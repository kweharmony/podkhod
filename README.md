# Персональный фитнес-ассистент

Учебный проект по курсу «Fullstack», 1 семестр.
Дневник силовых тренировок: записываешь подходы и видишь, растут ли рабочие веса.

**Стек:** React + TypeScript (Vite) · FastAPI · PostgreSQL + SQLAlchemy

## Назначение

Приложение хранит историю тренировок и считает по ней метрики прогресса:
объём тренировки, расчётный 1RM по упражнению, динамику замеров тела.

## Пользовательские сценарии

1. **Провести тренировку** — создать тренировку на сегодня, добавить упражнения,
   записать подходы (вес × повторения), сохранить.
2. **Повторить прошлую тренировку** — скопировать прошлый комплекс и подставить новые веса.
   При добавлении упражнения видно результат прошлого раза.
3. **Найти упражнение** — фильтры по группе мышц и оборудованию, поиск по названию.
4. **Посмотреть прогресс по упражнению** — график рабочего веса и 1RM по датам.
5. **Внести замеры тела** — вес и обхваты раз в неделю, график динамики.

## Экраны

| № | Экран | Маршрут | Содержимое | Сценарии |
|---|---|---|---|---|
| 1 | Вход и регистрация | `/login`, `/register` | формы входа и регистрации (логика — ЛР №4) | — |
| 2 | Дашборд | `/` | последняя тренировка, объём за неделю, кнопка «Начать тренировку» | 1, 2 |
| 3 | Тренировки | `/workouts` | история тренировок | 1, 2 |
| 3.1 | Одна тренировка | `/workouts/:id` | подходы по упражнениям, редактирование | 1, 2 |
| 3.2 | Новая тренировка | `/workouts/new` | активная тренировка, добавление упражнений | 1, 2 |
| 4 | Справочник упражнений | `/exercises` | сетка с фильтрами по мышцам и оборудованию, поиск | 3 |
| 4.1 | Карточка упражнения | `/exercises/:id` | GIF, инструкция, целевые мышцы | 3 |
| 5 | Прогресс | `/progress?exercise=42` | графики объёма и 1RM, выбор упражнения | 4 |
| 6 | Замеры тела | `/measurements` | форма ввода и график динамики | 5 |
| 7 | Страница не найдена | `*` | заглушка для неизвестных маршрутов | — |

Вложенные маршруты (3.1, 3.2, 4.1) отдельными экранами не считаются, но нужны роутеру.
Упражнение в маршруте прогресса — query-параметр, потому что это фильтр вида,
а не отдельная страница: экран тот же, меняется только выбранное упражнение.

### Решения по интерфейсу

- Список упражнений с фильтрами — один переиспользуемый компонент. В справочнике клик
  открывает описание, в тренировке он же показывается в модальном окне и добавляет
  упражнение. Экран тренировки при этом не размонтируется и введённые подходы не теряются.
- Карточка упражнения — часть справочника, отдельным экраном не считается.
- Состояние активной тренировки хранится в React Context, а не в компоненте страницы,
  чтобы данные не пропадали при переходе на другой экран.
