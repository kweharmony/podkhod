# Podkhod

Учебный проект по Fullstack. Дневник силовых тренировок: подходы, рабочие веса,
история и прогресс. Помощник даёт совет по данным пользователя.

## Стек

React + TypeScript, Vite, React Router, Tailwind CSS, shadcn/ui,
react-hook-form + zod, Motion, Recharts, Lucide, ESLint.
Backend: Python, FastAPI, PostgreSQL, SQLAlchemy, pwdlib (Argon2), PyJWT, httpx.

## Что работает

- Регистрация, вход, обновление токена и выход.
- Создание, просмотр, изменение, повторение и удаление тренировок.
- Добавление упражнений и подходов, изменение веса и повторений.
- Справочник: поиск, фильтры, добавление, изменение и удаление упражнений.
- Замеры тела: добавление, изменение и удаление.
- Дашборд и график рабочего веса и расчётного 1RM по данным из БД.
- Советы через Polza AI; без ключа или при недоступности сервиса — правила.

Тренировка создаётся в базе сразу. Выбор упражнения открывает справочник
с возвратом в тренировку. Данные сохраняются при переходах и перезагрузке.
Удалить упражнение, которое используется в тренировках, нельзя.

## Экраны

| Адрес | Что открывается |
|---|---|
| `/` | визитка |
| `/login`, `/register` | вход и регистрация |
| `/dashboard` | статистика и помощник |
| `/workouts` | история тренировок |
| `/workouts/new`, `/workouts/:id` | создание и редактирование тренировки |
| `/exercises` | справочник; `?workout=id` — выбор для тренировки |

## Структура

`frontend/src/app` — настройка и layout; `pages` — экраны;
`features/auth` — вход; `entities` — типы API и графики;
`shared` — общие компоненты и HTTP-клиент. За основу взят упрощённый FSD.

В `backend/app`: `routers` — маршруты, `models.py` — таблицы,
`schemas.py` — валидация, `crud.py` — операции БД, `logic.py` — расчёты,
`assistant.py` — запросы к модели, `security.py` — пароли и токены.

Демонстрационные данные и искусственные задержки убраны. Состояния загрузки,
ошибки и пустых данных зависят от настоящих запросов. После изменения данные
перечитываются с сервера. Формы проверяются в браузере и через Pydantic.

## Модель данных

Во всех таблицах есть первичный ключ id.

| Таблица | Основные поля и связи |
|---|---|
| user | email (уникальный), name, password_hash, height_cm |
| exercise | name, body_part, equipment, target, instruction |
| workout | user_id → user, date, title, note |
| workout_exercise | workout_id → workout, exercise_id → exercise, position |
| set | workout_exercise_id → workout_exercise, weight, reps |
| measurement | user_id → user, date, weight, chest, waist |
| advice | user_id → user, created_at, text, source |
| refresh_token | user_id → user, token_hash, expires_at |

Тренировка и упражнение связаны многие-ко-многим через workout_exercise.
Удаление тренировки каскадно удаляет её упражнения и подходы.
Объём и 1RM считаются из подходов, отдельно не хранятся.

## Запуск

Нужны Docker Desktop, Python 3.11+ и Node.js 22.12+.
Из корня проекта:

```powershell
docker compose up -d
cd backend
python -m venv .venv
.venv/Scripts/Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Копировать пример нужно только при первой настройке. Полученный случайный
секрет запишите в JWT_SECRET внутри .env. DATABASE_URL берётся из примера.
POLZA_API_KEY необязателен; модель задаётся POLZA_MODEL.
Настоящие пароли и ключи в Git не добавляются.

```powershell
uvicorn app.main:app --reload
```

Таблицы создаются автоматически. В старую таблицу user добавляется колонка
хеша пароля без удаления данных. Старые записи без пароля войти не могут —
для проверки зарегистрируйте новый аккаунт с другим email.

В другом терминале из корня:

```powershell
cd frontend
npm install
npm run dev
```

Сайт: http://127.0.0.1:5173. Swagger: http://127.0.0.1:5173/api/docs.
Vite пересылает /api на порт 8000. Справочник в новой базе пустой:
упражнение можно добавить через форму на странице «Упражнения».
Внешний датасет и загрузка медиа не требуются.

## Доступ

Argon2 хранит хеши паролей. JWT access действует 15 минут и хранится в памяти;
refresh — 7 дней в HttpOnly-cookie, в БД — его хеш. Выход отзывает текущий
refresh; уже выданный access истекает по своему сроку.
Тренировки, подходы, замеры и советы доступны владельцу. Справочник общий:
читать API можно без входа, менять — после входа. Для HTTPS включается
COOKIE_SECURE=true. Для размещения dist потребуется прокси /api на backend.

## Проверка

Из backend при запущенной базе:

```powershell
python -m unittest discover -s tests -v
```

Тесты используют отдельную временную схему PostgreSQL. Проверяют вход, токены,
права, CRUD и пересчёт объёма. Из frontend: `npm run build` и `npm run lint`.

Для показа: зарегистрироваться → добавить упражнение → создать тренировку →
добавить упражнение и подход → изменить вес → обновить страницу → открыть
прогресс → добавить замер → выйти. Для пустых данных нужен новый аккаунт,
для ошибки загрузки можно временно остановить backend.
